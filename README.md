Dataset Cleaning & Preprocessing – Task 1.2

Overview

This project focuses on cleaning and preprocessing a real-world student performance dataset using Python and Pandas.

Objectives

- Handle missing values
- Remove duplicate records
- Clean inconsistent formatting
- Convert attendance values into a suitable numeric format
- Validate the cleaned dataset

Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

Files

- "student_performance_cleaned.csv" – Final cleaned dataset
- "dataset_cleaning_preprocessing_1_2.ipynb" – Cleaning and preprocessing notebook

Cleaning Steps

1. Loaded the raw dataset
2. Identified and handled missing values
3. Removed duplicate records
4. Standardized text formatting
5. Cleaned the Attendance column
6. Performed final data validation
7. Exported the cleaned dataset as a CSV file

Result

The dataset was successfully cleaned and preprocessed, making it ready for further data analysis and machine learning tasks.
